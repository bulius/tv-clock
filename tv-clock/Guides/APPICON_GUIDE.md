# 📱 App Icon Setup with AppIcon.icon

This project uses Xcode's modern `.icon` file format for app icons instead of manually exporting PNG files.

---

## 🎯 What is AppIcon.icon?

Starting with Xcode 15 and later, Apple introduced a new `.icon` file format that:
- ✅ Automatically generates all required icon sizes
- ✅ Works across iOS, tvOS, watchOS, and macOS
- ✅ Simplifies icon management (single source file)
- ✅ Supports multiple icon variants and layers
- ✅ No need to manually export PNG files at different sizes

---

## 🔧 How to Use

### Step 1: Create an AppIcon.icon File

1. **In Xcode**, open your project
2. **Press `⌘N`** (File → New File)
3. **Choose**: Resource → **App Icon**
4. **Name**: `AppIcon.icon`
5. **Add to target**: Select your tvOS target
6. **Click**: Create

### Step 2: Design Your Icon

You have several options:

#### Option A: Use SF Symbols (Recommended for this project)

1. **Open** `AppIcon.icon` in Xcode
2. **In the icon editor**, click "SF Symbol"
3. **Search for**: `sun.min.fill` (matches our sunrise theme)
4. **Select it**
5. **Customize**:
   - Background: Gradient from `#FFD94D` (bright yellow) to `#F27B3A` (sunrise orange)
   - Symbol Color: White
   - Symbol Style: Filled with glass effect

#### Option B: Import Custom Artwork

1. **Prepare your artwork**: Single 1024×1024 PNG or SVG
2. **Open** `AppIcon.icon`
3. **Drag your image** into the preview area
4. **Xcode automatically generates** all required sizes

#### Option C: Use AppIconGenerator.swift Design

The `AppIconGenerator.swift` file contains the sunrise icon design. To use it:

1. **Build and run** your app
2. **Screenshot** the icon preview at 1024×1024
3. **Import that screenshot** into `AppIcon.icon`

## ✅ Setup in Your Project

### Update Asset Catalog

1. **Delete old asset references** (if any):
   - Old `AppIcon.appiconset` folders
   - Manually imported PNG files

2. **In `Assets.xcassets`**:
   - Remove old "App Icon" entry
   - It will be replaced by `AppIcon.icon`

3. **Configure Project Settings**:
   - Select your **tvOS target**
   - Go to **General** tab
   - Under **App Icons and Launch Screen**
   - Set **App Icon** to: `AppIcon`
   - Xcode will automatically find `AppIcon.icon`

## 💡 Pro Tips

### Multiple Icon Variants

You can create multiple `.icon` files for different contexts:
- `AppIcon.icon` - Main app icon
- `AlternateIcon.icon` - Dark mode variant
- `WinterIcon.icon` - Seasonal variant

### Testing Different Designs

1. Duplicate `AppIcon.icon`
2. Modify the copy
3. Switch between them in project settings
4. See which looks better on tvOS

### Version Control

`.icon` files work great with Git:
- Single file to track
- No large PNG files in repo
- Easy to review changes
- Clean diffs

## 🔍 Troubleshooting

### "I don't see App Icon option in New File"

**Solution**: Update Xcode to version 15 or later
- App Icon file type was added in Xcode 15
- Check: Xcode → About Xcode

### "Icon doesn't appear in Simulator"

**Solution**:
1. Clean build folder (`⌘⇧K`)
2. Delete app from Simulator
3. Quit and relaunch Simulator
4. Rebuild and run
5. Icons can take a moment to generate

### "Can I still use the old PNG method?"

**Answer**: Yes, but `.icon` is recommended:
- Easier to maintain
- Automatically handles all sizes
- Future-proof for new devices
- Less error-prone

If you prefer PNGs, keep one of the export scripts.
